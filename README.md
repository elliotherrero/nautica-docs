# nautica-docs

![CI](https://github.com/elliotherrero/nautica-docs/actions/workflows/ci.yml/badge.svg)

Web de Náutica Bahía: tienda y alquiler de material náutico en Puerto de Mazarrón. Dirigida a personas interesadas en conocer la empresa y sus servicios.

## Funcionalidades

- Página principal con la presentación de la empresa.

## Requisitos

- Un navegador web moderno.
- Git para clonar el repositorio.

## Cómo ejecutarlo en local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/elliotherrero/nautica-docs.git
   cd nautica-docs
   ```

2. Abre el archivo `index.html` en el navegador.
